# Email-Analysis-Lab
Hands-on phishing email analysis project focused on email header investigation, spoofed domain detection, Base64 attachment analysis, IOC extraction, and practical SOC investigation workflow using CyberChef and email forensics techniques.

#Overview
This project demonstrates hands-on phishing email analysis and SOC investigation techniques by examining suspicious emails, analyzing email headers, identifying spoofed domains, and investigating encoded attachments.

#Objectives
Analyze suspicious email headers
Identify spoofed organizations and sender domains
Trace originating IP addresses
Decode Base64-encoded attachments
Extract Indicators of Compromise (IOCs)

#Tools Used
CyberChef

#Skills Demonstrated
Email Header Analysis
Phishing Detection
Base64 Decoding
MIME Analysis
IOC Extraction
Attachment Investigation
Threat Analysis


#Investigation Summary
During this analysis, suspicious emails impersonating legitimate organizations were investigated. Email headers were reviewed to identify spoofing indicators, sender infrastructure, and authentication details. A Base64-encoded PDF attachment was decoded and analyzed using CyberChef to identify suspicious artifacts and hidden content.


#Indicators of Compromise (IOCs)
Suspicious Domain
Base64-encoded PDF attachment
